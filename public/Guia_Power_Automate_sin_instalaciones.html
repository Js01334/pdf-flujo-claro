Automatizar el renombrado de PDFs

Construye un flujo en Power Automate Desktop para Windows 10: recorre una carpeta, consulta cada documento en el sitio al que ya tienes acceso, compara dos datos y anexa el contenido de la columna 5 o NE.

Flujo local · Edge abierto e inicio de sesión manual
Condición de este caso: no se instalará software, extensión, paquete ni complemento. Usa únicamente Power Automate Desktop que ya esté disponible en el equipo, Edge ya instalado y acciones estándar de automatización de escritorio. No uses las acciones “Automatización web” de PAD si solicitan instalar o habilitar una extensión del navegador. En su lugar, interactúa con la ventana de Edge mediante acciones de interfaz de usuario, teclado y portapapeles.

Qué hará y qué no hará el flujo

Automatiza
  • Todos los archivos PDF del nivel elegido de una carpeta.
  • Separación del nombre por espacios.
  • Búsqueda con el primer dato, cambiando - por /.
  • Comprobación exacta de las columnas 1 y 2.
  • Renombrado conservando el nombre original y la extensión.
Requiere preparación y prueba
  • La persona abre Edge, inicia sesión y deja la lista de oficios visible.
  • Los elementos de UI se capturan en el equipo real con PAD; los selectores visuales pueden variar.
  • La lectura de filas se hace copiando la tabla al portapapeles. Primero verifica que Edge la copie como columnas separadas por tabuladores.

Ejemplo de entrada y resultado

Archivo: 284-2026 JA 20/2026.pdf

Nombre sin extensión → dividir por espacios → 284-2026, JA, 20/2026.

Consulta en la caja “Búsqueda..”: 284/2026 (solo se convierte el guion del primer dato).

Fila que cumple: columna 1 = 284-2026 y columna 2 = 20/2026, ambas exactas. Si su quinta columna contiene INC. SUSPENSIÓN DEFINITIVA, nuevo nombre: 284-2026 JA 20/2026 - INC. SUSPENSIÓN DEFINITIVA.pdf. Sin fila exacta: 284-2026 JA 20/2026 - NE.pdf.

El texto de la columna 5 se agrega, no sustituye ninguna parte del nombre. La captura recibida muestra como quinta columna “Autoridad/Destinatario”; confirma que el sitio conserva ese orden.

Antes de empezar

  1. Haz una carpeta de prueba con 2 o 3 copias de PDFs. No pruebes inicialmente con los originales.
  2. Abre Edge, inicia sesión a mano y navega hasta Lista de oficios.
  3. Comprueba que la tabla tiene, en este orden: No. de oficio (1), No. expediente (2), otras dos columnas, y Autoridad/Destinatario (5).
  4. En la tabla, selecciona una fila y cópiala a Bloc de notas. Debe pegar columnas separadas por tabuladores y filas separadas por saltos de línea. Bloc de notas ya viene en Windows; no instales nada. Si el copiado no conserva esa estructura, consulta la sección “Si la tabla no se copia como columnas”.
  5. Mantén el zoom, tamaño de ventana y posición de Edge constantes durante la ejecución. Desactiva temporalmente notificaciones que puedan cubrir la tabla.

Parte A · Capturar los controles una sola vez

En PAD crea un flujo nuevo, por ejemplo RenombrarPDF_Oficios. En el diseñador, captura los elementos como elementos de interfaz de usuario de ventana/escritorio con el selector incorporado de PAD. No instales la extensión de Edge.

Campo de búsqueda
Captura la caja “Búsqueda..” de la tabla. En ejecución, el flujo hará clic, Ctrl+A y escribirá la consulta.
Menú padre
Captura el elemento visible Expediente Electrónico. Para abrir el submenú usa la acción de mover el puntero a ese elemento; no hagas clic en el menú padre.
Primera opción
Con el submenú abierto, captura “Integrar expediente electrónico” (la primera opción mostrada en la captura). Después se hace clic en esa opción. Si la opción real que necesitas es otra, captura la opción correcta.
Tabla/filas
Captura la zona de resultados o una celda de la tabla para darle foco antes de Ctrl+A y Ctrl+C. Confirma que no se copia solo el texto del control.

La disponibilidad de “Mover el mouse a elemento de interfaz de usuario” depende de la versión instalada de PAD. Si no aparece, usa la acción de mouse que permita mover el puntero al centro del elemento capturado. Como último recurso, coloca el puntero por coordenadas sobre el menú, sin clic, y valida que el submenú se despliegue. Las coordenadas dependen del tamaño y escala de pantalla.

Parte B · Crear el flujo principal

1. Elegir carpeta y obtener PDFs

Mostrar cuadro de diálogo de selección de carpeta
Guarda la ruta seleccionada en CarpetaPDF. Si la carpeta está definida y no debe cambiar, puedes asignarla directamente en una acción de variable.
Obtener archivos de la carpeta
Carpeta: %CarpetaPDF%. Filtro: *.pdf. No incluir subcarpetas, salvo que realmente se requiera. Guarda la lista como ArchivosPDF.
Para cada
Itera ArchivoActual en %ArchivosPDF%. Mantén esta acción abierta hasta el final del proceso de un archivo y cierra el bloque “Fin”.

2. Descomponer el nombre de cada archivo

Obtener parte de ruta de archivo
Entrada: ruta de %ArchivoActual%. Usa la salida Nombre sin extensión como NombreBase. No dividas la extensión .pdf.
Reemplazar texto
Normaliza espacios dobles antes de dividir: activar expresiones regulares; buscar \s+; reemplazar por un espacio simple. Entrada %NombreBase%; salida NombreNormalizado. Si no tienes habilitado el uso de expresiones regulares en esa acción, omite la normalización y verifica que los nombres no tengan espacios repetidos.
Dividir texto
Texto: %NombreNormalizado%. Delimitador: un espacio. Salida: lista PartesNombre. En opciones, quitar elementos vacíos si esa opción está disponible.
Obtener número de elementos de lista
Lista: %PartesNombre%; guarda el total como CantidadPartes. Si es menor que 2, registra el archivo como “nombre no válido” y pasa al siguiente archivo.
Obtener elemento de lista
Índice 0 de %PartesNombre% → PrimerDato. Calcula IndiceUltimo = CantidadPartes - 1 con las acciones de variable/operador matemático disponibles; obtiene ese elemento → UltimoDato.
Reemplazar texto
Entrada: %PrimerDato%; buscar -; reemplazar por /; salida ConsultaWeb. No cambies el PrimerDato original: se usa para comparar la columna 1.

3. Abrir el submenú con hover y llegar a la tabla

  1. Antes de la ejecución, deja Edge abierto y autenticado. PAD debe operar sobre esa ventana, no sobre una ventana distinta.
  2. Usa Esperar a que la ventana exista o una espera corta que esté disponible en tu versión.
  3. Ejecuta Mover el mouse a elemento de interfaz de usuario con el elemento capturado “Expediente Electrónico”. Esta acción solo mueve el puntero; no hace clic. Espera a que aparezca el menú.
  4. Haz clic en el elemento capturado de la primera opción del submenú. No intentes hacer clic en el padre antes de mover el mouse.
  5. Espera a que cargue la lista de oficios. Repite esta navegación solo si la página se reinicia o sale de esa lista; no hace falta volver al menú por cada PDF si la tabla sigue visible.
Orden correcto: hover sobre menú padre → pausa/espera → clic en opción hija. Si el cursor se sale del menú antes del clic, el submenú se cierra; evita mover el puntero entre ambas acciones.

4. Buscar cada PDF

  1. Haz clic en el elemento capturado de “Búsqueda..”.
  2. Envía Ctrl+A para borrar el contenido anterior y escribe %ConsultaWeb%.
  3. Espera a que la tabla termine de filtrar. Usa la acción de espera disponible; si no hay indicador confiable, empieza con 1–2 segundos y ajusta observando el sitio. La acción no debe continuar antes de la actualización.
  4. Haz clic dentro de la tabla para asegurar que Edge reciba el teclado; envía Ctrl+A, luego Ctrl+C.
  5. Usa la acción integrada de PAD para obtener el texto del portapapeles y guárdalo en TextoTabla. No pegues la tabla en un archivo intermedio.

Si Ctrl+A en la tabla selecciona toda la página, puede copiar también encabezados y otros textos. El siguiente paso filtra encabezados al exigir que las columnas 1 y 2 coincidan con los dos datos del nombre. No uses “seleccionar todo” mientras el cursor esté en la caja de búsqueda: enfoca primero la zona de tabla.

5. Separar las filas y buscar coincidencia exacta

  1. Divide %TextoTabla% por salto de línea y guarda la lista LineasTabla. Según el portapapeles, puede requerirse dividir por CRLF o LF; prueba con una fila real y conserva el separador que entregue tu equipo.
  2. Inicializa CoincidenciaEncontrada en False y SufijoEncontrado vacío.
  3. Para cada LineaActual en LineasTabla, divide la línea por tabulador. El encabezado también se procesará, pero no debe coincidir con los datos.
  4. Verifica que la lista de celdas tenga al menos 5 elementos. Toma índice 0 como columna 1, índice 1 como columna 2 y el índice 4 como columna 5.
  5. Quita espacios al inicio/final de cada celda con la acción integrada de recortar texto (Trim), tanto en columnas 1/2 como en los datos del nombre.
  6. Condición: columna 1 es igual a %PrimerDato% Y columna 2 es igual a %UltimoDato%. No uses “contiene”; la comparación debe ser exacta.
  7. Si ambas coinciden: asigna el texto completo de la columna 5 a SufijoEncontrado, cambia CoincidenciaEncontrada a True y sal del bucle de filas.
  8. Si al terminar no hay coincidencia, asigna NE a SufijoEncontrado.
Idea de la condición por fila
Si celdas[0] = PrimerDato Y celdas[1] = UltimoDato
    SufijoEncontrado = celdas[4]
    CoincidenciaEncontrada = True
    salir del bucle
Si CoincidenciaEncontrada = False
    SufijoEncontrado = "NE"
Prueba imprescindible: abre el panel de variables en PAD y confirma cómo copia una fila. Los tabuladores, saltos de línea y filas pueden variar entre sitios y versiones de Edge. Si el texto no conserva las 5 celdas como 5 columnas, no ejecutes el renombrado masivo todavía; utiliza el modo de comprobación manual descrito abajo.

6. Limpiar el sufijo y renombrar

  1. Recorta %SufijoEncontrado%. Si está vacío, reemplázalo por NE.
  2. Windows no permite \ / : * ? " < > | en nombres. Usa la acción integrada “Reemplazar texto” para cambiar esos caracteres por guion bajo. La barra diagonal de la consulta jamás debe anexarse al nombre.
  3. Construye NuevoNombre como %NombreBase% - %SufijoSeguro%.pdf. Ejemplo: 284-2026 JA 20/2026 - INC. SUSPENSIÓN DEFINITIVA.pdf.
  4. Usa “Renombrar archivo(s)” sobre la ruta original. Selecciona “no sobrescribir” si la acción ofrece esa opción. Si no la ofrece, antes verifica que el archivo de destino no exista; ante una colisión, registra el caso y no lo renombres.
  5. Registra el nombre anterior, el sufijo y el nombre nuevo en una lista o archivo de texto opcional creado con acciones integradas de PAD.

Fin Para

Agregar nuevos clics a la página

  1. En el diseñador de PAD, crea una acción de clic de interfaz de usuario y captura el control objetivo con el selector incorporado.
  2. Inserta antes una acción de mover el mouse si el control está dentro de un submenú que solo aparece con hover.
  3. Agrega una espera pequeña entre hover y clic para que el menú termine de mostrarse.
  4. Para una cadena de submenús, repite: mover mouse a padre → esperar → mover mouse al hijo si abre otro submenú → esperar → clic solo en la opción final deseada.
  5. Valida con un archivo de prueba que la página cambió al lugar esperado antes de seguir con la tabla.

Importante: no uses “clic” sobre el menú principal para intentar mostrar el submenú. La captura indica que se abre al pasar el puntero.

Cuando no se puede leer la tabla por portapapeles

Si al copiar no se mantienen las columnas, la página puede impedir copiar la tabla o entregarla como texto plano sin separadores. Como no se permite instalar nada, no hay una forma universal de extraer con exactitud esas celdas sin el complemento de automatización web, una API del sitio o controles accesibles.

En ese caso, conserva automatizados la selección de PDFs, separación del nombre y escritura de la búsqueda, pero configura una revisión humana: pausa tras cada consulta, inspecciona las columnas 1, 2 y 5, anota el sufijo en una variable de PAD y confirma antes del renombrado. No marques una coincidencia solo porque el texto aparezca en alguna parte de la página; deben concordar las dos columnas del mismo renglón.

El OCR integrado de PAD puede probarse como alternativa si ya está disponible en el equipo, pero puede confundir números, diagonales, guiones o texto en filas envueltas. No lo uses para renombrar sin validar varios casos reales y una condición de aprobación manual.
